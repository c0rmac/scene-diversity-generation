# Scene diversity generation

Results page for polarised consensus-based optimisation (PCBO) generating diverse, statically stable mug-and-spoon scenes: every verified disconnected component of the set of strongly stable equilibria that one lean PCBO run reached in 1,000 iterations (1.45 million oracle calls), with discovery curves, the share of new components per iteration, checks of the method, and the mathematical description of the solver.

Live page: https://c0rmac.github.io/scene-diversity-generation/

Files: `index.html` (the page), `poses.js` (component poses), `views_persp.js` and `views_side.js` (rendered views).
