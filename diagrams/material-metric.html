Pb is a fixed set of material points in body coordinates. Each dot is drawn at Rbp + tb in the current scene; the set moves with the body. Open and filled markers identify the same p in the reference and current scenes. The distance uses every sample, averaging squared displacement within each body before adding the two body contributions and taking the square root.
